# Sigma GMaps Scraper

Aplicativo desktop para extrair leads do Google Maps, analisar oportunidades e organizar campanhas de WhatsApp.

## Apoie o projeto

Se este projeto ajudar você, deixe uma ⭐ no GitHub e compartilhe.

## Executar localmente

```bash
npm install
npm start
```

## Build

```bash
npm run build:portable
```
