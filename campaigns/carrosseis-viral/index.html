Como postar — fábrica diária (Google Flow + HTML)

  1. Gere 2 novas selfies/dia no Flow com o mesmo prompt base + seed diferente (já validei: 720×1280 portrait funciona, 1080×1350 é crop direto). Mantém reconhecimento.
  2. Troque só o hook — use banco de 30 ganchos POV/me when/how it looks. Nunca mude look/background.
  3. Recheio = valor salvável — 1 carrossel = 1 promessa (cravings, energia, pele). 5–7 slides, último slide sempre CTA “salve / comente palavra”.
  4. Exporte 1080×1350: abra cada card em tela cheia (clique) → screenshot ou use “Exportar PNGs” (usa html2canvas em 3×). Poste como carrossel.
  5. Poste diário às 11h e 19h. Formato repetível vence por volume — igual no print: 12 posts, views espalhadas, sem fluke.
